# Mobile Drawing App

App that lets you draw pictures and save them to a gallery. 

## Instructions for Build and Use

Steps to build and/or run the software:

1. Open the project in android studios 
2. Go to the devices button in the middle of the top of your screen
3. Wirelessly connect your android phone to the app
4. if you don't have an android phone, you can emulate a fake phone from your computer be 'adding a new device'

Instructions for using the software:

1. Drag your finger across the screen to draw
2. change color and size of your stroke through the buttons at the bottom of teh screen
3. Save your art by clicking the save button at the bottom of the screen and view it in the gallery.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Android Studio Ladybug (2024.2.1) or newer
* Android Gradle Plugin 8.7.3
* Android SDK 35 (Platform)
* Java Development Kit (JDK) 11
* AndroidX AppCompat 1.7.1
* Google Material Components 1.14.0
